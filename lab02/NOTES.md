1. Git - система контроля версий, которая работает непосредственно на компьютере и отслеживает изменения в коде

2. GitHub - платформа для хранения Git-репозиториев и совместной работы

3. git diff - показывает, какие изменения были произведены, но ещё не сохранены через git add
4. git diff --staged - показывает, какие изменения уже сохранены через git add и будут отправлены со следующим коммитом

## Использованные команды:

git status - показывает текущее состояние репозитория и рабочей директории

git diff - показывает различия между состояниями файлов в репозитории

git diff --staged - показывает разницу между областью индексации и последним коммитом

## Ветки

Ветка в Git — это отдельная линия разработки, которая позволяет работать над изменениями независимо от других веток.

При создании нового коммита ветка перемещается на этот новый коммит, сохраняя предыдущие коммиты в истории.

Слияние объединяет изменения из одной ветки с другой. При слиянии Git переносит изменения из указанной ветки в текущую.
