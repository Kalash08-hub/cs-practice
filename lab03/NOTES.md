## git  diff / git show / git log

1. Git diff - показывает, что изменилось после последнего коммита

2. Git show - подробно показывает, что изменилось в конкретном (выбранном) коммит

3. Git log - показывает список всех коммитов, а также краткую информацию про них (автор, дата)

## Отличие git restore от git restore --source=

1. git restore - возвращает сохранение к последнему коммиту. Правки бы сбросились к состоянию 
на момент последнего коммита.

2. Git restore --source= - возвращает сохранение к определенному коммиту. Правки бы сбросились к состоянию, 
на момент выбранного коммита.
